Dungeoneer Read Me

To the run game install
~CS66main.py
~CS66adts.py
~Map.py
~game_data.json
~loot_table.json
~entities.py
~utils.py

The user must also have python installed 
To play the game the user is to go into the file CS66main.py and click run. The goal of the game is to explore rooms, gain gold, buy potions, defeat enemies the player will find in rooms, collect weapons, and defeat the boss.

To play you must enter commands. Valid commands are
~look
~move
~fight
~inventory
~use
~path
~help
~exit
~shop
